# AI Study Agent 🤖📚

AI Study Agent is an intelligent learning platform designed to help students study smarter using AI.

## ✨ Features

- 🤖 AI Learning Agent
- 💬 AI Study Tutor
- 📄 Upload and search study documents
- 🧠 AI-generated flashcards
- 📝 AI-generated study notes
- 📋 AI-generated tests and quizzes
- 📊 Learning progress tracking
- 🎯 Adaptive learning recommendations
- 🔐 User authentication
- ⚙️ Personalized learning settings
- 🔎 RAG-based study material retrieval

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- SQLite for local development

### AI
- OpenAI API
- RAG
- ChromaDB
- LangGraph
